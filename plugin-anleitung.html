Plugins bauen

Worum es geht

Ein Plugin-Ordner ist ein ganz normaler Ordner auf deinem Gerät – oder in Nextcloud, Drive, Syncthing … WMap liest daraus Kartenebenen und Erweiterungen. Du kannst mehrere Ordner hinzufügen; WMap merkt sie sich, und „Neu einlesen“ holt geänderte Dateien.

  • Nur eine Ebene: GeoJSON-Datei in den Ordner legen – fertig.
  • Ebene mit Namen, Beschreibung, Farbe: ein Unterordner mit einer wmap-plugin.json.
  • Kartenkacheln (z. B. eine geologische Karte, WMS): auch über wmap-plugin.json.
  • Richtiges Plugin mit Programmcode (Erweiterung): eine JavaScript-Datei, die auf der Karte etwas tut.

Wo es geht

  • WMap-App (Android, Windows, macOS, Linux): Ordner wählen, WMap merkt ihn.
  • Chrome und Edge (auch als installierte Web-App): ebenso – nach einem Neustart fragt der Browser einmal, ob WMap wieder lesen darf.
  • Firefox und Safari: nur einmal einlesen. Diese Browser bieten die Schnittstelle zum dauerhaften Ordnerzugriff (File System Access) nicht an – Mozilla hält sie für zu riskant, weil eine Webseite damit in echte Ordner schreiben könnte. Zum Aktualisieren denselben Ordner einfach noch einmal wählen.

Hinzufügen: Plugins → Hinzufügen → „Plugin-Ordner hinzufügen“.

Aufbau eines Ordners

Meine Plugins/
├── Hochsitze.geojson             → Ebene „Hochsitze“
├── Messnetz/
│   ├── wmap-plugin.json          → Ebene mit Name, Beschreibung, Farbe
│   └── messstellen.geojson
├── Geologie/
│   └── wmap-plugin.json          → Kartenkacheln (tiles)
└── Wetterwarnung/
    ├── wmap-plugin.json          → Erweiterung (script)
    └── main.js
  • Lose .geojson/.json-Dateien werden zu je einer Ebene, benannt nach der Datei.
  • Lose .js-Dateien werden zu Erweiterungen (siehe unten).
  • Alles in einem Unterordner mit wmap-plugin.json gehört zu diesem Plugin.
  • Unterordner bis 5 Ebenen tief; Dateien und Ordner mit Punkt am Anfang werden übergangen.

wmap-plugin.json – Ebene aus GeoJSON

{
  "name": "Messnetz Harz",
  "description": "Grundwasser-Messstellen, monatlich aktualisiert.",
  "operator": "Wasserverband Harz",
  "attribution": "© Wasserverband Harz, CC BY 4.0",
  "data": "messstellen.geojson",
  "color": "#1a73e8",
  "colorBy": "pegel"
}
nameName in WMap (sonst der Ordnername)
descriptionBeschreibung auf der Plugin-Seite
operator, attributionAnbieter und Quellenangabe
dataeine Datei oder eine Liste (["a.geojson", "b.geojson"]); fehlt es, nimmt WMap alle GeoJSON-Dateien im Ordner
colorFarbe der Punkte, Linien und Flächen
colorByEigenschaft mit Zahlen – eingefärbt von blau (niedrig) bis rot (hoch)

GeoJSON in WGS84 (Längen- und Breitengrad), wie es QGIS, geojson.io & Co. schreiben. Eigenschaften der Objekte zeigt WMap beim Antippen.

wmap-plugin.json – Kartenkacheln

{
  "name": "Geologische Karte",
  "tiles": "https://example.org/tiles/{z}/{x}/{y}.png",
  "attribution": "© Landesamt …",
  "minzoom": 6,
  "maxzoom": 16,
  "opacity": 0.7
}

Für einen WMS-Dienst eine Kachelvorlage mit BBOX={bbox-epsg-3857}, CRS=EPSG:3857, WIDTH=512&HEIGHT=512.

Erweiterung – ein richtiges Plugin

{
  "name": "Wetterwarnung",
  "description": "Zeigt Unwetterwarnungen als Fläche.",
  "type": "extension",
  "script": "main.js"
}
// main.js – ein ES-Modul in einer Datei
export function activate(wmap) {
  wmap.onMapReady((map) => {
    map.addSource('warnung', { type: 'geojson', data: 'https://example.org/warnungen.geojson' });
    map.addLayer({ id: 'warnung', type: 'fill', source: 'warnung',
      paint: { 'fill-color': '#e03131', 'fill-opacity': 0.3 } });
  });
  wmap.addMenuItem('warning', 'Warnungen', () => wmap.toast('Warnungen an'));
}
wmap.mapdie Karte (MapLibre)
wmap.maplibreglMapLibre selbst (Marker, Popups …)
wmap.onMapReady(fn)fn(map), sobald die Karte geladen ist
wmap.addMenuItem(icon, text, fn)Eintrag im Menü der Karte (Symbole: Material Symbols)
wmap.toast(text)kurze Meldung unten
wmap.storage.get(k) / .set(k, v)kleiner Speicher nur für diese Erweiterung
wmap.versionWMap-Version
  • Eine Datei, ohne import anderer eigener Dateien (Bibliotheken per https://-Adresse gehen).
  • Erweiterungen laufen erst, wenn du sie auf der Plugin-Seite aktivierst – sie dürfen in WMap alles, auch deinen Standort sehen.
  • Nach dem Ändern: „Neu einlesen“, dann die Karte neu öffnen.

Teilen

Plugin-Ordner bleiben auf deinem Gerät. Anderen gibst du ein Plugin, indem du den Ordner teilst – oder es auf der Plugin-Seite über „Plugin anbieten“ in den Katalog stellst (privat oder öffentlich, mit WMap-Konto).
