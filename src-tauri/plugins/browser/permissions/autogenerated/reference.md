## Default Permission

Weblinks öffnen (Ansicht mit Leiste oder Standardbrowser), Android: teilen und in die Zwischenablage

#### This default permission set includes the following:

- `allow-open`
- `allow-share`
- `allow-share-file`
- `allow-copy`
